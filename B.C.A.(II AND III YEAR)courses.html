Bachelor of Computer Applications (BCA) - 2nd Year

The second year of our BCA program transitions students from computing basics into advanced system development architectures and software methodologies. The curriculum builds deep, hands-on competence in object-oriented programming frameworks, enterprise database configuration, advanced web scripting, and operating systems to prepare students for core technical software engineering pathways.

Duration: 1 Year (2 Semesters — Sem III & Sem IV)
Eligibility: Successful academic promotion from BCA 1st Year or direct admission via an engineering diploma lateral entry pathway.

2nd Year Technical Core

OOP

Object-Oriented Java

Master modular development principles using Java, including classes, inheritance, polymorphism patterns, and exception setups.

OSY

Operating Systems

Explore core system kernel structures, memory allocation models, CPU scheduling algorithms, and storage management parameters.

SEN

Software Engineering

Study structural agile lifecycles, UML modeling, system requirement blueprints, and software verification testing methods.

CNW

Computer Networks

Learn layered OSI network models, packet routing configurations, transport layer metrics, and secure network infrastructure setups.

WAD

Web App Development

Build dynamic, secure server-side applications using modern server scripting languages, API setups, and framework structures.

PYT

Python Programming

Develop versatile scripting systems, object parsing procedures, data processing paths, and developer library implementations.

CGR

Computer Graphics

Implement visual matrix rendering algorithms, 2D/3D geometry transformations, clipping calculations, and interface elements.

BDA

Business Analytics

Leverage systemic mathematical data frameworks, regression tracking scripts, and business data optimization software blocks.

Bachelor of Computer Applications (BCA) - 3rd Year

The final year of the BCA program is dedicated to cutting-edge specializations, cloud frameworks, and industrial application engineering. Students engage with advanced emerging tech domains while applying their cumulative skills within a full-scale Capstone Project development lifecycle, graduating as elite, industry-ready software engineers.

Duration: 1 Year (2 Semesters — Sem V & Sem VI)
Eligibility: Academic clearance of the minimum required credits up to BCA 2nd Year (Sem IV).

3rd Year Advanced & Capstone Tracks

AIM

AI & Machine Learning

Train predictive algorithmic datasets, neural structures, supervised learning nodes, and automated data parsing loops.

CCT

Cloud Computing

Deploy scalable remote virtualization systems, microservices, container routing grids, and cloud architectural setups.

CBY

Cyber Security

Implement cryptographic encryption protocols, system vulnerability patches, firewalls, and data access defenses.

MAD

Mobile App Dev

Construct native and cross-platform smartphone utilities using industry-standard SDKs and system compilation tracks.

EAT

Enterprise Apps

Structure high-volume commercial software utilizing robust backend corporate patterns and enterprise framework services.

DMI

Data Mining & BI

Extract patterns from complex storage systems using advanced clustering logic and intelligence report interfaces.

IOT

Internet of Things

Program dynamic microcontroller hardware sensors, cloud telemetry channels, and mesh node communication lines.

PRJ

Capstone Project

Compile a multi-week original software application, build documentation files, and pass final technical board evaluation panels.
